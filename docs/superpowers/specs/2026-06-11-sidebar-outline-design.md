# 文件与大纲侧栏设计

## 目标

在 EasyMarkdown 主工作区左侧增加可折叠侧栏，集中提供最近文件与 Markdown 大纲导航，同时保持应用轻量、键盘可用和三语一致。

## 布局

- 侧栏位于编辑区和预览区左侧，展开宽度约 240px。
- 侧栏开关位于第二行格式工具栏最左侧、“标题”分组之前。
- 开关使用内置 SVG 侧栏图标，不引入图标依赖。
- 折叠后侧栏完全隐藏，工作区恢复全部宽度。
- 折叠状态保存在 `localStorage`，新窗口沿用该状态。
- 小窗口下侧栏覆盖内容区域，避免挤压编辑和预览到不可用宽度。

## 文件标签

- 数据直接复用 `recentFiles` 模块及其订阅机制。
- 点击文件名在当前窗口打开。
- 每项右侧提供两个图标按钮：
  - 新窗口打开。
  - 删除。
- 删除按钮打开三选项确认：
  - 仅移除最近记录。
  - 同时删除磁盘文件。
  - 取消。
- “仅移除记录”为安全默认选项。
- 同时删除磁盘文件时，提示中显示完整路径，只调用后端删除该单个明确文件。
- 删除当前正在编辑的文件后，编辑内容保留，当前文件路径清空，状态变为未保存文件。
- 文件标签底部不提供“清空记录”。

## 大纲标签

- 从当前编辑器文本解析 ATX 标题 `#` 到 `####`。
- 忽略 fenced code block 中的伪标题。
- 去除标题尾部可选的闭合 `#`，保留标题文字。
- 按 H1–H4 层级缩进。
- 标题存在后代时显示折叠按钮；折叠某标题会隐藏到下一个同级或更高级标题之前的全部后代。
- 文档编辑后实时刷新，同时尽量保留仍存在节点的折叠状态。
- 点击标题：
  - 编辑或分屏模式：定位编辑器对应行并聚焦。
  - 纯预览模式：定位预览区对应的 H1–H4。

## 空状态

- 文件：显示“暂无最近文件”。
- 大纲：显示“大纲内容为空”。
- 空状态使用简短说明，不添加装饰插图。

## 可访问性

- 标签使用 `tablist`、`tab`、`tabpanel` 语义。
- 所有图标按钮均有三语 `aria-label` 与 `title`。
- 当前标签同时使用文字、选中状态和底部指示线。
- 折叠按钮提供 `aria-expanded`。
- 焦点样式沿用现有工具栏规范。
