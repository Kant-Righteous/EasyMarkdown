# 分屏拖动与文件拖放设计

## 范围

- 分屏模式下，编辑区和预览区之间的分隔线可以拖动。
- 分屏比例不持久化，每个窗口初始为 50:50。
- 支持把 `.md`、`.markdown`、`.txt` 文件拖入窗口并在当前窗口打开。
- 多文件拖入时，打开第一个受支持文件。
- 新建文件和切换文件共用未保存确认流程。
- 未保存确认按钮统一为“保存 / 不保存 / 取消”，同步中文、英文、法文。

## 交互

- 分屏分隔线显示为 1px，保留 6px 拖动热区。
- 编辑区和预览区最小宽度均为可用分屏宽度的 20%。
- 仅在分屏模式和桌面横向布局下显示分隔线。
- 文件拖入窗口时显示轻量边框反馈；离开或放下后立即移除。
- 不支持的文件类型不执行打开操作。
- 打开拖入文件时沿用现有未保存内容三选项确认。

## 实现边界

- `splitPane.ts` 负责比例计算和 Pointer Events 绑定。
- `fileDrop.ts` 负责扩展名筛选和 Tauri 拖放事件绑定。
- `fileTransition.ts` 负责通用未保存确认流程。
- `file.ts` 继续负责实际读取、保存、新建和窗口标题更新。
- 不新增第三方依赖，不改变现有文件读取后端。

## 验证

- 纯函数测试覆盖比例限制、拖放文件筛选和未保存决策。
- DOM/CSS 测试覆盖分隔条结构、显示条件和拖放反馈。
- 完整测试与生产构建必须通过。
