# EasyMarkdown 最近打开设计

## 目标

在“文件”菜单中增加“最近打开”，让用户能够快速重新打开最近使用的 Markdown 或文本文件，并可选择在当前窗口或新窗口中打开。

## 菜单交互

- “文件”菜单新增“最近打开”子菜单，位置在“打开”之后。
- 子菜单最多显示 10 条记录，按最近成功打开或保存的时间倒序排列。
- 每条记录显示文件名；完整路径通过辅助文本或悬停提示提供，用于区分同名文件。
- 每条记录继续展开一个子菜单，包含：
  - “在当前窗口打开”
  - “在新窗口打开”
- 最近记录为空时显示不可操作的“暂无最近文件”。
- 列表底部提供“清空最近记录”，仅清除历史记录，不删除磁盘文件。
- 二级和三级菜单沿用现有菜单的关闭规则：点击菜单外部、按 `Escape` 或成功执行操作后关闭。

## 最近记录

- 使用 `localStorage` 持久化最近记录，不新增 Tauri 插件或后端存储文件。
- 每条记录只保存规范化后的绝对路径。
- 新记录移到列表首位，路径相同的旧记录自动去重。
- 列表超过 10 条时移除最旧记录。
- 以下操作成功后更新最近记录：
  - 通过“打开”选择并读取文件；
  - 从“最近打开”读取文件；
  - “另存为”或首次保存成功后获得文件路径。
- 普通保存只刷新已有记录的顺序，不产生重复项。
- “新建”不写入最近记录。

## 当前窗口打开

- 复用现有文件读取与编辑器状态更新流程。
- 当前文档有未保存修改时，沿用现有的放弃修改确认。
- 用户取消确认时，不读取目标文件，也不改变最近记录顺序。
- 文件读取成功后更新内容、当前路径、文件名、保存基线、脏状态和窗口标题。

## 新窗口打开

- 使用 Tauri 2 的 Webview 窗口 API 创建独立编辑窗口。
- 新窗口使用唯一标签，避免多次创建发生标签冲突。
- 文件路径通过新窗口 URL 的查询参数传入；应用启动时读取参数并加载文件。
- 创建新窗口不影响当前窗口的内容和未保存状态，因此不弹出放弃修改确认。
- 新窗口完成文件读取后更新最近记录；创建或读取失败时提示错误。
- 补充创建 Webview 窗口所需的 Tauri capability 权限，保持权限范围仅覆盖本功能。

## 异常处理

- 文件已移动、删除、无权限或内容无法读取时，显示包含操作名称的错误提示。
- 从最近记录打开失败时，将该路径从最近记录移除，避免持续显示失效项。
- `localStorage` 数据缺失、格式错误或不可用时，回退为空列表，不阻止编辑器启动。
- 新窗口创建失败时保留最近记录，因为该文件本身不一定失效。

## 代码边界

- 新增独立的最近记录模块，负责读取、校验、排序、去重、截断、移除和清空。
- `file.ts` 提取按指定路径打开文件的公共流程，供文件选择器、最近记录和新窗口启动共用。
- 菜单绑定代码负责渲染最近记录及分发“当前窗口/新窗口”操作，不承担持久化逻辑。
- `main.ts` 在窗口初始化时处理 URL 中的待打开文件路径。
- HTML 和 CSS 只增加嵌套菜单容器、箭头、空状态和路径提示所需结构与样式，不重构无关界面。

## 测试与验收

- 单元测试覆盖最近记录的倒序、去重、10 条上限、移除、清空和损坏数据回退。
- 单元测试覆盖新窗口 URL 参数的编码与解析，确保包含空格、中文和特殊字符的路径可正确传递。
- 构建检查覆盖 TypeScript、Vite 和 Tauri capability 配置。
- 手动验证：
  - 普通打开、保存和另存为后记录顺序正确；
  - 同一路径不会重复出现；
  - 当前窗口打开会正确处理未保存修改；
  - 新窗口打开不改变当前窗口；
  - 失效文件提示错误并从列表移除；
  - 清空记录不会影响磁盘文件；
  - 嵌套菜单在常用窗口尺寸下不超出可视区域。
