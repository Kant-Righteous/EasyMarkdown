# EasyMarkdown 移动端预览布局设计

## 目标

在现有 Vanilla TypeScript、Vite 和 Tauri 2 桌面应用中增加移动端预览布局。移动布局用于浏览器窄屏验证和后续手机端设计准备，不初始化 Android 或 iOS，不引入前端框架，也不改变现有桌面布局。

## 启用规则

- 视口宽度进入手机断点时自动启用移动布局。
- URL 查询参数 `?mobile=1` 强制启用移动布局，不受视口宽度限制。
- 未满足以上条件时保持现有桌面 UI。
- 移动模式只改变布局和控件组织，复用现有应用状态、Markdown 渲染和命令处理。

## 页面结构

移动端采用单栏应用壳，纵向依次为：

1. 文档信息与高频操作区。
2. 预览、分屏、编辑三项视图切换。
3. 编辑器或预览工作区。
4. 可收起的底部 Markdown 工具栏。

页面需要考虑底部安全区，工作区占据除固定控件以外的剩余高度。

## 顶部区域

第一行显示：

- 当前文档名。
- 已保存或未保存状态，包含文字与状态圆点。

第二行从左到右显示：

1. 侧栏图标按钮。
2. 文件按钮。
3. AI 对话保存模式按钮。
4. 撤销图标按钮。
5. 重做图标按钮。
6. 保存按钮，固定在最右侧。

按钮使用紧凑尺寸，但可点击区域应接近触控建议尺寸。保存是主要操作，使用现有选中/深色视觉语言。

## 文件菜单

文件按钮打开移动端简化菜单，包含：

- 新建
- 打开
- 另存为
- 重命名
- 导出 PDF

这些入口复用现有命令。当前阶段不适配移动原生文件系统，也不修改 PDF 导出实现。

桌面端的“最近打开”不放入移动文件菜单。最近文件由侧栏的文件页承载。

## 文档侧栏

点击文件按钮左侧的侧栏图标，从左侧打开覆盖式抽屉。抽屉顶部提供“文件”和“大纲”两个互斥 Tab。

### 文件页

- 显示现有最近文件列表。
- 复用现有文件打开能力。
- 不复制桌面右键菜单和鼠标悬停操作。

### 大纲页

- 按标题级别显示树状层级。
- 有子标题的父节点显示折叠图标。
- 子标题使用缩进、竖向层级线和分支线表达归属。
- 折叠一个父节点只隐藏该节点的后代，不影响其他一级标题。
- 点击标题继续复用现有大纲导航行为。

## 视图切换

视图按钮顺序固定为：

1. 预览
2. 分屏
3. 编辑

编辑和预览保持单栏显示。分屏在窄屏下采用上下排列，编辑区在上、预览区在下，并保留现有滚动同步语义。两区之间显示可识别的分隔控制，但本阶段不要求实现移动手势调整比例。

## 底部工具栏

底部固定显示五个等宽、水平等距的分类按钮：

1. 标题
2. 字体
3. 列表
4. 块级
5. 插入

分类按钮打开位于工具栏上方的触控菜单，继续通过现有 `data-command` 命令执行插入逻辑。

### 标题

- H1 一级标题
- H2 二级标题
- H3 三级标题

只显示当前命令层实际支持的标题级别。

### 字体

- 加粗
- 斜体
- 下划线
- 删除线
- 高亮

### 列表

- 无序列表
- 有序列表
- 任务列表

### 块级

- 引用
- 代码块
- 公式块
- Mermaid 图表

### 插入

- 超链接
- 图片
- 表格
- 水平分割线
- 内联代码
- 内联公式
- 脚注

工具栏上沿中央显示独立的细线图标按钮。展开时可收起工具栏；收起后底部中央保留恢复按钮。该按钮不占用五个分类按钮的水平空间。

## 预览交互映射

移动预览继续使用现有 Markdown 渲染能力，包括 KaTeX、脚注、任务列表、有限 MDX 和 Mermaid。

- 任务列表复选框可在预览中点击，并回写匹配源码行。
- 引用、代码块、公式块和 Mermaid 图表显示复制源码按钮。
- 复制成功时按钮短暂显示成功状态。
- 这些交互只属于实时预览，不进入 PDF 输出。
- 外部链接继续使用现有链接处理逻辑。

## 移动端不映射的桌面控件

- 不显示语言切换，移动端预览固定使用中文。
- 不显示内容缩放按钮，后续手机实现使用平台手势；本阶段不实现手势缩放。
- 不照搬桌面右键菜单。
- 不照搬侧栏和分屏的鼠标横向拖拽交互。
- 不显示桌面状态栏；文件名、保存状态和视图状态已在移动顶部与 Tab 中表达。

## 技术方案

- 新增一个小型移动模式判定模块，纯函数解析视口状态和 `mobile=1` 参数，便于单元测试。
- 在现有 HTML 中增加移动专用控件，桌面和移动控件共享 `data-command`、`data-view` 和应用状态。
- 使用根元素状态类或数据属性切换布局，不复制编辑器、预览容器或 Markdown 渲染流程。
- 扩展现有工具栏事件委托，使移动菜单、侧栏和工具栏收起控制沿用相同命令分发。
- 主要通过 `src/style.css` 的移动状态选择器实现布局，桌面规则保持不变。
- 不修改 Rust 代码。

## 测试与验收

自动测试至少覆盖：

- `?mobile=1` 强制启用。
- 普通查询参数不强制启用。
- 窄屏自动启用，宽屏保持桌面模式。
- 移动模式下命令和视图按钮标记完整。
- 桌面端菜单、工具栏和分屏标记仍存在。
- README 包含桌面开发、浏览器手机尺寸预览和强制移动预览说明。

浏览器验收覆盖：

- 宽屏桌面布局无回归。
- 320px、390px 和横屏窄高度下控件不溢出。
- 文件菜单、侧栏两个 Tab、大纲折叠、三种视图和五类工具菜单可用。
- 底部安全区、工具栏收起和弹出菜单位置正确。
- 任务勾选和块复制在移动预览中可操作。

## 明确排除

- Android 或 iOS 项目初始化
- 原生移动文件系统适配
- 移动 PDF 导出适配
- 云同步
- React、Vue、Flutter 或 React Native
- 与移动布局无关的大规模重构
