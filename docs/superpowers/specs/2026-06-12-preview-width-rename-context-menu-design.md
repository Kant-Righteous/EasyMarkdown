# 预览宽度、重命名与右键菜单设计

## 预览宽度

- 分屏模式正文最大宽度从 74ch 提升到 80ch。
- 独立预览模式正文最大宽度为 96ch。
- 表格、代码块、MDX 卡片组和展开标签可以使用预览区全部可用宽度。
- 打印和 PDF 样式保持不变。

## 重命名

- 顶部“文件”菜单增加“重命名”。
- 侧栏文件项右键菜单中的“重命名”作用于被点击文件。
- 其他区域右键菜单中的“重命名”作用于当前文件。
- 未保存且没有磁盘路径的新文件禁用重命名。
- 输入框默认显示完整文件名；空名称、路径分隔符、Windows 非法字符和已存在目标会阻止操作。
- 当前文件重命名后同步状态栏、窗口标题、侧栏选中态和最近文件记录。

## 自定义右键菜单

- 编辑区包含：表情符号、撤销、剪切、复制、粘贴、粘贴为纯文本、全选、检查。
- 普通区域包含：刷新、另存为、打印、重命名、检查。
- 删除“书写方向”和“更多工具”。
- 菜单支持鼠标点击、Escape 关闭和点击外部关闭。
- “检查”通过 Tauri 后端命令打开开发者工具，发布构建启用 devtools feature。

## 后端

- `rename_file` 只允许在原目录内修改文件名，拒绝目录和已存在目标。
- `open_devtools` 打开当前 WebView 的开发者工具。
- `open_emoji_picker` 在 Windows 发送 Win+. 快捷键；非 Windows 返回不支持错误。
