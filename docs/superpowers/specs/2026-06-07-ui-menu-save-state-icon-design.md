# EasyMarkdown UI、菜单、保存状态与图标设计

## 目标

在不改变 Vanilla TypeScript + HTML/CSS 架构的前提下，统一界面为紧凑的黑白灰风格，重组顶部菜单，集中修复保存状态逻辑，并替换默认 Tauri 图标。

## 界面与响应式布局

- 顶部使用紧凑两行布局。
- 第一行左侧为“文件”“操作”下拉菜单，右侧为“编辑 / 预览 / 分屏”视图切换。
- 第二行保留全部 Markdown 高频按钮，并按标题、强调、列表、块级、插入分组。
- 继续使用 Tauri 配置中的 `760x500` 最小窗口尺寸，避免关键控件被压缩到不可操作。
- 第一行始终保持菜单与视图切换可见，不使用横向滚动。
- 第二行在空间不足时独立横向滚动；中等宽度隐藏分组标签并缩小间距。
- 颜色仅使用无彩灰阶。已保存状态使用绿色，未保存状态使用红色。
- 交互状态通过背景、边框、文字粗细共同表达，不只依赖颜色。

## 菜单交互

- “文件”菜单包含：新建、打开、保存、另存为、导出 PDF。
- “操作”菜单包含：撤销、重做。
- 菜单按钮使用 `aria-expanded` 表示状态；任意时刻最多打开一个菜单。
- 点击其他菜单、菜单外部、按下 Escape、执行菜单项后关闭菜单。
- 下拉层使用绝对定位并由不裁切的第一行容器承载，避免被工具栏滚动区域截断。
- 保存、撤销、重做菜单项显示 Windows 快捷键提示。

## 快捷键

- 只在 `shortcuts.ts` 中注册一次文档级快捷键监听。
- 仅识别 `Ctrl`，不加入 `Meta` 或 macOS 分支。
- 支持 `Ctrl+S`、`Ctrl+Z`、`Ctrl+Y`、`Ctrl+B`、`Ctrl+I`、`Ctrl+K`。
- 撤销和重做使用浏览器原生编辑命令，作用于聚焦的 Markdown 文本框。
- Markdown 按钮通过现有命令函数修改内容，由统一编辑器通知流程更新预览与保存状态。

## 保存状态

- `state.ts` 提供唯一的 dirty state 计算入口：当前内容与 `lastSavedContent` 比较。
- 输入、Markdown 命令、撤销和重做都通过编辑器内容变化通知调用该入口。
- 新建、打开、保存、另存为只更新文件元数据和 `lastSavedContent`，随后统一重算 `isDirty`。
- 导出 PDF 不更新 `lastSavedContent` 或 `isDirty`。
- 打开或保存后，如果内容与保存基线相同，状态显示“已保存”；否则显示“未保存”。

## 图标

- 新图标为圆角方形深灰背景，中央使用白色“EM”字标。
- 生成 Tauri 所需的 PNG、ICO 和 ICNS 资源，覆盖现有同名图标文件。
- `tauri.conf.json` 保持显式引用 Windows `icon.ico` 和其他平台资源。
- 不删除或改动无关资源。

## 验证

- 为纯状态计算和快捷键映射增加自动化测试。
- 运行 TypeScript/Vite 构建。
- 运行 Tauri 配置或构建检查，确认图标资源可读取。
- 在最小窗口和常用桌面宽度检查菜单、滚动、视图切换与状态提示。
