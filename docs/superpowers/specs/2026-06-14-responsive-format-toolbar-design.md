# 第二行格式工具栏设计

## 目标

将第二行格式工具栏扩展为五个单行分组，在空间充足时显式展示全部功能；空间不足时按用户指定优先级收纳低优先项，同时兼容中文、英文和法文界面。

## 功能范围

- 标题：H1、H2、H3
- 强调：加粗、斜体、下划线、删除线、高亮
- 列表：无序列表、有序列表、任务列表
- 块级：引用、代码块、公式块、图表
- 插入：超链接、图片、表格、水平分割线、内联代码、内联公式、脚注

## 布局与收纳

工具栏始终保持单行，不允许换行。按钮使用统一尺寸和同一套单色线性图标，标题及常见排版符号可使用 H1、H2、H3、B、I、U、S 字形。

空间不足时按以下顺序处理：

1. 隐藏五个分组的可见文字标签，但保留 `aria-label` 和按钮提示。
2. 强调组依次收纳斜体、下划线、删除线，始终保留加粗和高亮。
3. 列表组收纳任务列表，始终保留无序列表和有序列表。
4. 插入组依次收纳脚注、水平分割线、表格，始终保留超链接、图片、内联代码和内联公式。

标题组和块级组始终完整展示。被收纳的按钮进入所属分组的独立“更多”菜单，不使用混合所有功能的全局菜单。

## 行为

工具栏通过 `ResizeObserver` 响应真实可用宽度。每次测量先恢复全量状态；若溢出，则隐藏标签并按顺序将低优先按钮移动到对应分组菜单。宽度恢复后，按钮回到原位置。

命令插入标准 Markdown 或常见扩展语法：

- 下划线：`<u>文本</u>`
- 删除线：`~~文本~~`
- 高亮：`==文本==`
- 任务列表：`- [ ] 项目`
- 公式块：`$$` 包围的块
- 图表：Mermaid 围栏代码块
- 图片：`![说明](./image.png)`
- 内联代码：反引号包围
- 内联公式：`$` 包围
- 脚注：脚注引用和定义模板

公式和图表本次只负责插入语法，不引入 KaTeX 或 Mermaid 渲染依赖。

## 多语言与无障碍

所有组名、按钮 `title`、`aria-label` 和菜单项均提供中文、英文、法文翻译。图标按钮保持至少 30×30 像素点击区域，提供清晰的悬停、焦点和打开状态。
