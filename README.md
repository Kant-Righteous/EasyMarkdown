# 极简Markdown

一个轻量、快速、稳定的本地Markdown桌面编辑器。

## 特点

- 🚀 轻量快速 - 启动迅速，运行流畅
- 💻 本地编辑 - 文件保存在本地，保护隐私
- 🎨 简洁界面 - 干净清爽，专注写作

## 快速开始

### 安装

1. 下载最新版本
2. 解压到任意目录
3. 运行 `EasyMarkdown.exe`

### 使用

1. 启动应用
2. 新建或打开Markdown文件
3. 开始写作，实时预览效果
