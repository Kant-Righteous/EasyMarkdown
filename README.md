# EasyMarkdown

一个轻量、快速、稳定的本地Markdown桌面编辑器。专为追求效率的写作者设计，让你专注于内容本身。

![EasyMarkdown预览](demo.png)

## 特点

- 🚀 轻量快速 - 启动迅速，运行流畅
- 💻 本地编辑 - 文件保存在本地，保护隐私
- 🎨 简洁界面 - 干净清爽，专注写作
- 📝 实时预览 - 边写边看，所见即所得
- 📄 导出PDF - 一键生成高质量PDF文档
- ⌨️ 快捷键支持 - 高效操作，提升写作速度
- 👁️ 多种视图模式 - 编辑、预览、分屏自由切换
- 💾 快捷保存AI对话 - 轻松保存AI生成的内容

## 快速开始

### 安装

1. 下载最新版本
2. 运行 `setup.exe`

### 使用

1. 启动应用
2. 新建或打开Markdown文件
3. 开始写作，实时预览效果
